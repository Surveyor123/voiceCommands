Third-party binaries, based on the official "vosk" 0.3.45 Windows (win_amd64) package on PyPI:

- libvosk.dll (Vosk API, Apache-2.0; Kaldi and OpenBLAS linked in) — unmodified.
- libwinpthread-1.dll (winpthreads, MIT-style) — unmodified.
- libstdc++-6.dll and libgcc_s_seh-1.dll (GCC runtime, GPL-3.0-or-later with the GCC Runtime
  Library Exception 3.1) — stripped with `strip --strip-unneeded` to remove debugging
  symbols. The code is otherwise unchanged; only non-essential symbol/debug information
  was removed. Functionality is identical to the original binaries.
